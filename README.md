SSCC(渋渋コンピュータ部)のDiscordサーバー用のbotです。
コードやリリースノートはClaude,ChatGPT,Geminiが書いています。

最新版は `SSCCbot Ver.4.0` です（過去のバージョンも各フォルダに残しています）。

# 🤖 SSCCbot 機能一覧

SSCCbotで利用できるコマンドと自動化機能のまとめです。Discord上で `/commands` を実行しても、同じ一覧を確認できます。

## 👤 プロフィール機能

- **`/profile member` `[メンバー]`**
  - 指定したメンバーの自己紹介を、自己紹介チャンネルから探して自分だけに表示します。
- **`/profile role` `[ロール]`**
  - 指定したロール（例: 30期）を持つメンバーの自己紹介をまとめて、自分だけに表示します（最大10名）。ロールは一覧から選べます。

## 🎂 誕生日機能

- **`/birthday entry` `[月]` `[日]`**
  - 自分の誕生日を登録します（うるう年の2/29も対応。平年は2/28にお祝いします）。
- **`/birthday show` `[メンバー]`**
  - 指定したメンバー（省略時は自分）の誕生日と、次の誕生日までの日数を確認します。
- **`/birthday everyone`**
  - 登録されている全員の誕生日を、月日順の一覧で表示します。
- **誕生日の自動お祝い通知**
  - 誕生日当日（日本時間）に、誕生日通知チャンネルへ自動でお祝いを送ります。

## 📅 日程調整・投票システム

- **`/schedule` `[タイトル]` `[候補日]` `[期限]` `[対象ロール]` `[何分前]`**
  - 【管理者用】日程調整パネルを作成します。候補日はカンマ区切りで最大24個、期限は `YYYY-MM-DD HH:MM`（日本時間）または `なし` で指定します。
  - ボタンで投票し、もう一度押すと取り消せます。期限が来ると自動で締め切り、結果を発表します（作者・管理者は手動で締め切ることもできます）。
  - 結果発表では、最多票の候補を表示します。同数の場合は管理者の票が多い候補を優先し、それでも並んだ場合は「同率」と表示します。
- **`/poll` `[質問]` `[選択肢]` `[期限]` `[対象ロール]` `[何分前]`**
  - 誰でも作れる簡易投票パネルを作成します。選択肢はカンマ区切りで2〜24個、期限の指定方法は `/schedule` と同じです。
  - 結果発表では、勝者と投票者のメンションを表示します。同票の場合は「同率首位」と表示します。
- どちらのパネルも、Botを再起動してもボタンがそのまま使えます。
- **未回答者へのリマインド**: 「対象ロール」と「何分前」（期限の何分前か。例: `1440` で1日前）を指定すると、その時刻に、対象ロールのうち、まだ回答していない人だけにメンションして知らせます。
  - どちらも、期限を指定したときだけ使えます。省略すると、リマインドはありません。
  - メンションが多いときは、50人ずつに分けて送ります。回答を取り消した人は、未回答として扱います。

## 📋 出席管理・ランキングシステム

- **`/attend pass`**
  - 【管理者用】本日の出席受付を開始し、4桁のパスワードを発行・確認します。
- **`/attend entry` `[パスワード]`**
  - パスワードを入力して、本人の出席を登録します。
  - 5回続けて間違えると、10分間入力できなくなります。
- **`/attend ranking` `[期間]`**
  - 出席ランキング（今月 / 今年度 / 総合）を、自分だけに表示します。
  - 同じ回数の人は同順位です（1位が3人なら全員1位、次は4位）。自分の順位も下に表示されます。
- **`/attend stats`**
  - 出席の統計を、自分だけに表示します。今月・今年度・全期間の開催回数と平均出席者数、前月との比較、最多出席の日、直近6か月の推移（文字のグラフ）、自分の出席率が見られます。
- **`/attend reset`**
  - 【管理者用】すべての出席データをリセットします。
- **出席ランキングの自動通知**
  - 毎月1日 9:00 に前月分、4月1日 9:10 に前年度分のランキングを、ランキング通知チャンネルへ自動で送ります。

## ✨ ロール・自動化機能

- **`/newrole` `[ロール名]` `[絵文字]` `[題名]`**
  - 【管理者用】複数のリアクションロールを、1つのパネルにまとめて作成します。ロール名と絵文字はカンマ区切りで、数を揃えて指定します。
  - 題名は省略できます（省略時は「✨ ロール付与パネル」）。
  - Botが止まっている間にリアクションを付け外ししても、起動時に自動でロールへ反映されます（詳しくは下の「Botが止まっていたときの補完」を参照）。
- **フォーラム新規投稿通知**
  - 対象のフォーラムに新規スレッドが作成されたとき、対応するロールを自動でメンションして通知します。
- **VC開店通知**
  - 誰もいないボイスチャンネルに最初の人が入ると、通知チャンネルへ「VCが開店しました」と、希望者のロールをメンションして知らせます。
  - 同じVCでは、10分以内に入退室を繰り返しても連続では通知しません。
  - 希望者のロールは、`/newrole` のリアクションロールで配ると、メンバーが自分で選べて便利です。
  - 設定（`vc_notify_channel_id` と `vc_notify_role_id`）が無いサーバーでは、何も起きません。
- **新規参加者の歓迎**
  - サーバーに新しいメンバーが参加すると、歓迎チャンネルに、本人へのメンション付きで歓迎メッセージを投稿します。
  - 文面は、設定エリアの `welcome_lines` で、サーバーごとに変えられます。`{intro}` は自己紹介チャンネルへのリンクになります。`welcome_lines` を書かなければ、標準の文面になります。
  - 設定（`welcome_channel_id`）が無いサーバーでは、何も起きません。Discord標準の「ウェルカムメッセージ」と重なる場合は、どちらかをOFFにしてください。

## 🎲 お楽しみ

- **`/omikuji`**
  - 今日のおみくじを引きます（大吉〜凶、ラッキーカラー、ラッキーアイテム）。結果は、自分だけに表示されます。
  - 1日1回です。同じ日に何度引いても同じ結果で、日本時間の0時を過ぎると引き直せます。結果は人ごとに違います（同じ日でも、引く人によって変わります）。
- **`/random member` `[人数]` `[ロール]`**
  - サーバーのメンバーから、ランダムに抽選します（重複なし）。Botは対象外です。
  - 人数は1〜20人で、省略時は1人です。ロールを指定すると、そのロールを持つ人だけが対象になります。

## 🗓️ 予定の通知

管理者が登録した予定を、指定した時刻にチャンネルへ通知します。

- **`/reminder add` `[日時]` `[内容]` `[何分前]` `[繰り返し]` `[ロール]` `[チャンネル]`**
  - 【管理者用】予定の通知を登録します。日時は日本時間で `YYYY-MM-DD HH:MM` の形式です（例: `2026-12-01 19:00`）。
  - 「何分前」を指定すると、予定の時刻よりも前に通知します（例: `60` で1時間前。省略時は予定の時刻ちょうど）。
  - ロールを指定すると、通知でそのロールをメンションします。チャンネルを省略すると、コマンドを実行したチャンネルに通知します。
  - 「繰り返し」は、毎日・毎週・毎月・毎年から選べます（省略時は1回だけ）。毎月は、その日が無い月（31日など）は月末に通知し、翌月は元の日付に戻ります。毎年の2/29は、平年は2/28に通知します。
  - 繰り返しの予定は、削除するまで続きます。Botが止まっていて過ぎた回は、通知せずに次の回へ進みます。
  - 通知は1回の予定につき1回です。「前日」と「当日」の両方に知らせたい場合は、2件登録してください。
  - 1サーバーで同時に登録できるのは50件までです。
- **`/reminder list`**
  - 登録中の予定を、日時の順に確認します（自分だけに表示）。
- **`/reminder delete` `[ID]`**
  - 【管理者用】登録した予定を削除します。IDは `/reminder list` で確認できます。繰り返しの予定は、以降の分もすべて削除されます。

### 個人用の予定（`/myreminder`）

自分だけの予定を登録できます（管理者でなくても使えます）。

- **`/myreminder add` `[日時]` `[内容]` `[何分前]` `[繰り返し]`**
  - 個人用の予定を登録します。1人10件までです。
  - 予定の時刻になると、**コマンドを実行したチャンネル**に、あなたへのメンション付きで通知が届きます。通知の本文には予定の内容を載せず、「📝 内容を確認する」ボタンを押した**本人にだけ**、内容が表示されます（他の人が押しても、内容は見えません）。
  - Discordの仕様で、Botが予定の時刻に「自分だけに見えるメッセージ」を直接送ることはできないため、この形にしています。他の人には、あなた宛てのリマインドがあること（メンションと、残り時間）だけが見えます。
  - 内容を確認できるのは、通知から7日間です（その後は、ボタンを押しても期限切れと表示されます）。
- **`/myreminder list`** / **`/myreminder delete` `[ID]`**
  - 自分の予定を確認・削除します（他の人の予定は表示も削除もできません）。

## 🎖️ 称号ロール

条件を満たした人に、Botが称号のロールを自動で付与します。条件と対象のロールは、設定エリアの `title_roles` で決めます。

- **条件の種類**
  - `attend_total`: 累計の出席回数が `value` 回以上（例: 初めての出席は `1`、出席10回は `10`）
  - `join_years`: サーバーに参加してから `value` 年以上（例: 参加1周年は `1`）
  - `birthday_registered`: 誕生日を登録済み
- **付与のタイミング**: 出席登録・誕生日登録の直後と、1日1回の確認（参加1周年など、時間で条件を満たすもの）です。
- **お知らせ**: 獲得すると、Botのお知らせ用チャンネル（`bot_notify_channel_id`）に「称号を獲得しました」と投稿します（設定が無い場合は、ロールの付与だけ行います）。そのサーバーで**初めて**その称号を獲得した人は、特別な「初獲得」のお知らせで表彰されます。
- **手動で外したロールは、再付与しません。** 付与した記録を残しているためです。手動で付けたロールを持っている人には、お知らせせずに記録だけ残します。
- **設定に称号を追加した日の扱い**: すでに条件を満たしている人には、その日の確認で、お知らせなしでロールを付与します（過去の分でチャンネルが埋まらないようにするためです）。「初獲得」の表彰は、その後に新しく獲得した人から対象になります。
- **`/title list`**: 称号の一覧と、自分の獲得状況を、自分だけに表示します（未獲得の称号は、出席回数などの進み具合つき）。
- 出席回数は、現在の出席データ（`/attend reset` でリセットした後の分）から数えます。

## 🗳️ 匿名意見箱

匿名で、意見や要望を投稿できます。意見箱用のフォーラムチャンネルを使います。

- **`/suggest`**
  - 入力フォームに、題名と内容を書いて送ると、意見箱のフォーラムに、Botが新しい投稿を作ります。管理者用チャンネルには、管理者ロールへのメンション付きで通知が届きます。
- **追加の意見**: 投稿に付いている「💬 匿名で意見を追加」ボタンから、他のメンバーも匿名で意見を足せます。
- **管理者の返信**: 管理者は、投稿に普通に返信します（こちらは匿名ではありません）。
- **クローズ**: 解決したら、管理者が「✅ 解決してクローズ（管理者）」ボタンを押すと、投稿に【解決済み】が付き、ロックしてアーカイブされます。
- **完全匿名です。** 投稿者のIDは、記録も、ログへの出力もしません（投稿・通知・ファイルのどこにも入りません）。
  - ただし、Botを動かしている人がコードを書き換えれば、記録できてしまいます。「匿名」と案内する場合は、運営で「コードを書き換えて投稿者を調べない」というルールを共有してください。

## 🟢 Bot起動通知

Botが起動（接続）したときに、Botのお知らせ用チャンネル（`bot_notify_channel_id`）へ「🟢 SSCCbotが起動しました」と、バージョンと時刻を投稿します。設定エリアの `startup_notify_role_id` を指定すると、そのロール（起動通知を希望する人）にメンションします。起動のたびに1回です。

## 🔄 Botが止まっていたときの補完

Botの停止中や、Discord側の一時的なエラーで通知できなかった場合も、次のように補完します。

- 誕生日・月例ランキング・年度末ランキングの通知は、起動後と30分ごとに確認し、未送信の分を送ります。月例・年度末ランキングは、予定日から3日以内であれば遅れて送ります。
- 自動締め切りの結果発表に失敗した場合は、次回起動時に自動で再試行します。
- 称号は、起動直後と1日1回の確認で、条件を満たしている人に付与します。
- リアクションロールのパネルは、起動時に現在のリアクションとロールを突き合わせて、停止中に付け外しされた分を反映します。
  - Botが付与したロールだけを対象にするため、管理者が手動で付けたロールは外れません。
  - 以前から使っているパネルは、初回の同期では「リアクションしているのにロールが無い人」への付与だけが行われます。停止中にリアクションを外した人の分は、この更新より前のものは判別できません。
  - ずれを一括で直したいときは、`bot.py` の `REACTION_ROLE_STRICT_SYNC` を一時的に `True` にして再起動し、直後に `False` へ戻してください（そのロールを手動で付けた人からも外れるので、ロールが1つのパネルだけで管理されている場合のみ使えます）。
- 予定の通知は、Botが止まっていて時刻を過ぎても、予定の時刻から60分以内であれば遅れて通知します。それ以上過ぎた予定は、古い通知を避けるため見送ります。

# 🛠️ セットアップ（Botを自分のサーバーで動かす場合）

## 動作環境

- Python 3.9 以上
- discord.py 2.x（`pip install discord.py`）

## 1. Discord Developer Portal の設定

1. [Discord Developer Portal](https://discord.com/developers/applications) でアプリケーションを作成し、Bot を追加します。
2. Bot の設定画面で、次の2つの **Privileged Gateway Intents** をONにします（OFFのままだと起動できません）。
   - **Message Content Intent**
   - **Server Members Intent**
3. Bot のトークンをコピーします。

## 2. Botをサーバーに招待

招待URLのスコープは `bot` と `applications.commands` を選びます。Botには次の権限が必要です。

- チャンネルを見る / メッセージを送る / 埋め込みリンク / メッセージ履歴を読む / リアクションを追加
- ロールの管理（リアクションロール・称号ロールの付与に使います）
- 意見箱のフォーラムでは、投稿の作成・スレッドでのメッセージ送信・スレッドの管理（クローズ時のロックとアーカイブに使います）
- 「すべてのロールにメンション」（フォーラム通知で、メンション不可のロールを呼ぶ場合）

また、次の点も確認してください。

- **Botのロールの位置**: リアクションロール・称号ロールで付与するロールよりも、上に配置します。
- **チャンネルの権限**: Botが、自己紹介チャンネル・各通知チャンネル・対象のフォーラム・VC開店通知を見守るボイスチャンネルを見られるようにします。

## 3. `bot.py` の設定

`bot.py` の冒頭にある「設定エリア」を書き換えます。

| 項目 | 内容 |
| --- | --- |
| `TOKEN` | Botのトークン |
| サーバーID（`SERVER_CONFIGS` のキー） | Botを使うサーバーのID。複数サーバーは同じ形式で追加できます |
| `notify_channel_id` | フォーラム新規投稿の通知を送るチャンネル |
| `bot_notify_channel_id` | Botからのお知らせ（起動通知・称号獲得のお知らせ）を送るチャンネル（使わない場合は行ごと削除） |
| `ranking_channel_id` | 出席ランキングの通知を送るチャンネル |
| `intro_channel_id` | 自己紹介チャンネル |
| `birthday_notify_channel_id` | 誕生日通知を送るチャンネル |
| `vc_notify_channel_id` | VC開店通知を送るチャンネル（使わない場合は行ごと削除） |
| `welcome_channel_id` | 新規参加者の歓迎メッセージを送るチャンネル（使わない場合は行ごと削除） |
| `suggestion_forum_id` | 意見箱のフォーラムチャンネル（使わない場合は行ごと削除） |
| `suggestion_notify_channel_id` | 意見箱に新しい投稿があったときに知らせる、管理者用チャンネル（使わない場合は行ごと削除） |
| `admin_role_id` | 管理者ロール（`/schedule` などの管理者用コマンドを使えるロール） |
| `vc_notify_role_id` | VC開店通知を希望する人のロール（使わない場合は行ごと削除） |
| `startup_notify_role_id` | Bot起動通知を希望する人のロール（使わない場合は行ごと削除） |
| `forum_role_map` | 「フォーラムのID: メンションしたいロールのID」の組。複数追加できます |
| `welcome_lines` | 歓迎メッセージの文面（1行ずつのリスト）。サーバーごとに変えられます。`{intro}` は自己紹介チャンネルのリンクになります（使わない場合は項目ごと削除） |
| `title_roles` | 称号ロールの条件（`role_id`・`type`・`value`）のリスト。種類は `attend_total` / `join_years` / `birthday_registered`（使わない場合は項目ごと削除） |

IDは、Discordの設定で「開発者モード」をONにして、各項目を右クリックするとコピーできます。

## 4. 起動

```
python bot.py
```

`ログインしました: ○○` と表示されれば成功です。起動時にコマンドが同期され、少し待つとDiscord上にスラッシュコマンドが表示されます。

古いバージョンで登録されたコマンドは、起動時に自動で整理されます。表示が古いままのときは、Discordを再読み込み（`Ctrl + R`）してください。

# 📁 データファイルと運用の注意

## 自動で作られるファイル

Botを動かすフォルダに、次のファイルが自動で作られます。誕生日やユーザーIDなどが含まれるため、**公開しないでください**（GitHubにアップロードしないよう、`.gitignore` に追加しておくことをおすすめします）。

| ファイル | 内容 |
| --- | --- |
| `attendance_data.json` | 出席データ |
| `persistent_votes.json` | 日程調整・投票のデータ |
| `birthdays.json` | 誕生日の登録データ |
| `reaction_roles.json` | リアクションロールの設定 |
| `notify_state.json` | 通知済みの記録（二重送信の防止用） |
| `reaction_role_state.json` | リアクションロールの同期用の記録 |
| `reminders.json` | 予定の通知のデータ（管理者用・個人用）と、個人用の通知の内容（7日間） |
| `titles.json` | 称号の付与済みの記録（手動で外した称号を再付与しないためのもの） |
| `backups/` | 自動バックアップ（上のデータファイルを、日付ごとのフォルダにコピーしたもの） |

データを引き継ぐときは、これらのファイルをまとめてコピーしてください。ファイルが壊れていた場合は、`○○.json.corrupt-日時` という名前で退避され、Botは起動を続けます。

## 自動バックアップ

- 毎日、その日の最初の確認時（Botの起動直後、または日付が変わった直後）に、上のデータファイルを `backups/日付/` へコピーします。
- 直近14日分を残し、それより古いものは自動で削除します（日数は `bot.py` の `BACKUP_KEEP_DAYS` で変更できます）。
- **復元の手順**: Botを止めて、戻したい日付のフォルダの中身を、`bot.py` と同じフォルダへコピーしてから、Botを起動します。
- `backups/` にも誕生日などの個人情報が入るため、`.gitignore` に追加して、公開しないでください。
- バックアップは、Botを動かしているPCと同じ場所に保存されます。PCごと壊れる場合に備えて、たまに別の場所にもコピーしておくと安心です。

## 運用の注意

- **トークンを公開しない**: トークンを書き込んだ `bot.py` は、公開リポジトリにアップロードしないでください。もし公開してしまった場合は、Developer Portalでトークンを再発行してください。
- **Botを二重に起動しない**: 同じBotを2か所で動かすと、データの破損や通知の重複が起きます。
- **ログを確認する**: エラーは `⚠️` 付きでターミナルに表示されます。通知や結果発表が届かないときは、まずログを確認してください。
