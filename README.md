SSCC(渋渋コンピュータ部)のDiscordサーバー用のbotです。
コードやリリースノートはClaude,ChatGPT,Geminiが書いています。
# 🤖 SSCCbot 機能一覧

SSCCbotで利用できるコマンドと自動化機能のまとめです。

## 👤 プロフィール機能

* **`/profile member` `[メンバー]`**
* 指定したメンバーの自己紹介を表示します。


* **`/profile grade` `[期名]`**
* 指定した期のメンバーの自己紹介をまとめて自分だけに表示します。



## 🎂 誕生日機能

* **`/birthday entry` `[月]` `[日]`**
* 自分の誕生日を登録します（うるう年の2/29も対応）。


* **`/birthday show` `[メンバー]`**
* 指定したメンバー（省略時は自分）の誕生日を確認します（自動お祝い通知付き）。


* **`/birthday everyone`**
* 登録されている全員の誕生日を月日順の一覧で表示します。



## 📅 日程調整・投票システム

* **`/schedule` `[タイトル]` `[候補日]` `[期限]`**
* 管理者必須の日程調整を作成します（自動締め切り・永続化対応、投票者のメンション付き結果発表）。


* **`/poll` `[質問]` `[選択肢]` `[期限]`**
* 誰でも自由に作れる簡易投票パネルを作成します（永続化対応、勝者・投票者メンション付き結果発表）。



## 📋 出席管理・ランキングシステム

* **`/attend pass`**
* 【管理者用】本日の出席受付を開始し、4桁のパスワードを発行・確認します。


* **`/attend entry` `[パスワード]`**
* パスワードを入力して本人の出席を登録します。


* **`/attend ranking` `[期間]`**
* 出席ランキング（今月 / 今年度 / 総合）を自分だけに表示します。


* **`/attend reset`**
* 【管理者用】すべての出席データをリセットします。



## ✨ ロール・自動化機能

* **`/newrole` `[ロール名]` `[絵文字]`**
* 【管理者用】複数のリアクションロールパネルを一度に作成します。


* **フォーラム新規投稿通知**
* 対象のフォーラムに新規スレッドが作成された際、対応するロールを自動メンションして通知します。
