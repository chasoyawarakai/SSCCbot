🐛 1. 出席ランキングの同率表示を修正
* 同じ回数の人が、同じ順位で表示されるようになりました！
* これまでは、同じ回数でも登録順に1位・2位・3位と分かれていました。
* 1位が3人なら全員が🥇になり、次の人は4位です。月例・年度末の自動通知のランキングも同じです。
* /attend ranking の下に、自分の順位も表示されます。

🗓️ 2. 予定の通知が大幅パワーアップ
* 繰り返しの予定と、自分専用の予定が使えるようになりました！
* /reminder add に「繰り返し」を追加しました（毎日・毎週・毎月・毎年）。削除するまで続きます。毎月31日の予定は、31日が無い月は月末に通知します。
* /myreminder add で、自分専用の予定を登録できます（管理者でなくても使えます）。
* 自分専用の予定は、登録したチャンネルで、あなたへのメンションと「📝 内容を確認する」ボタンだけが投稿されます。内容は、ボタンを押した本人にだけ表示されます（確認できるのは通知から7日間）。
* /myreminder list と /myreminder delete で、自分の予定を確認・削除できます。

⏰ 3. 投票・日程調整の「未回答者リマインド」
* 期限が近づいたら、まだ回答していない人にだけお知らせします！
* /schedule と /poll に「対象ロール」と「何分前」を追加しました。
* 期限の何分前かに、対象ロールのうち、まだ回答していない人だけにメンションが届きます（例: 1440 で1日前）。
* 指定しなければ、これまでどおりです。

📊 4. 出席統計を追加
* /attend stats で、出席の状況を詳しく見られるようになりました！
* 今月・今年度・全期間の開催回数と平均出席者数、前月との比較、最多出席の日、直近6か月の推移（文字のグラフ）、自分の出席率が見られます。

🎖️ 5. 称号ロールを追加
* 出席回数などに応じて、称号のロールが自動で付きます！
* 条件は、累計の出席回数、サーバー参加からの年数、誕生日の登録から選べます。
* 獲得すると、お知らせが投稿されます。
* そのサーバーで初めて称号を獲得した人は、特別なお知らせで表彰されます🏆
* /title list で、称号の一覧と、自分の獲得状況・進み具合を確認できます。

🗳️ 6. 匿名意見箱を追加
* 匿名で、意見や要望を投稿できるようになりました！
* /suggest で題名と内容を送ると、意見箱のフォーラムに投稿されます。投稿者は、管理者にも分かりません。
* 投稿の「💬 匿名で意見を追加」ボタンから、他のメンバーも匿名で意見を足せます。
* 管理者は、投稿に返信して、解決したらボタンでクローズします（【解決済み】が付きます）。

🎉 7. 楽しい機能を追加
* /omikuji: 今日の運勢が引けます（1日1回・自分だけに表示）。運勢、ラッキーカラー、ラッキーアイテムが出ます。同じ日は何度引いても同じ結果で、結果は人ごとに違います。
* /random member: メンバーからランダムに抽選できます（重複なし・ロールで対象を限定可）。
* /birthday show に、次の誕生日までの日数が表示されるようになりました。
* 新しくサーバーに入った人に、歓迎メッセージが自動で届きます。

🟢 8. その他
* Botが起動したとき、お知らせチャンネルに「起動しました」と通知されます（起動通知を希望する人にメンション）。
* データの自動バックアップを追加しました（毎日1回・直近14日分）。
