🔄 1. リアクションロールが、Botの停止中の変更にも対応
* Botが止まっている間にリアクションを付け外ししても、起動時にロールへ反映されるようになりました！
* リアクションをしているのにロールが付いていない人には、ロールを付与します。
* リアクションを外した人からは、Botが付けたロールを外します（管理者が手動で付けたロールは外れません）。
* 以前から使っているパネルは、初回の同期では付与だけが行われます。この更新より前に、停止中にリアクションを外した人のロールは外れません。

🗓️ 2. 予定の通知機能を追加（管理者用）
* 管理者が登録した予定を、指定した時刻にチャンネルへ通知できるようになりました！
* /reminder add [日時] [内容] で予定を登録します（日時は日本時間 例: 2026-12-01 19:00）。
* 「何分前」を指定すると、予定の前に通知できます（例: 60 で1時間前）。
* ロールを指定すると、通知でそのロールをメンションします。
* /reminder list で登録中の予定を確認でき、/reminder delete で削除できます。
* Botが止まっていて時刻を過ぎても、予定の時刻から60分以内なら、起動後に遅れて通知します。
* 1つの予定につき通知は1回です。前日と当日の両方に知らせたいときは、2件登録してください。

⚙️ 運営の方へ
* 新しい設定項目はありません。そのまま更新できます。
* 次のファイルが自動で作られます（バックアップの対象に加えてください）: reaction_role_state.json、reminders.json
* リアクションロールのずれを一度に直したい場合は、bot.py の REACTION_ROLE_STRICT_SYNC を一時的に True にして、1回だけ再起動してください。その後は False に戻してください（手動で付けたロールも外れるため、1つのロールが1つのパネルだけで管理されている場合に限ります）。
